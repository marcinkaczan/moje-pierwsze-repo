# Mój projekt DevOps

## Opis projektu

To repozytorium zostało utworzone w ramach nauki pracy z systemem kontroli wersji **Git** oraz platformą GitLab/GitHub.

Projekt służy do ćwiczenia podstawowych operacji, takich jak:

- tworzenie repozytorium,
- edycja plików,
- zapisywanie zmian,
- wykonywanie commitów,
- korzystanie z formatowania Markdown.

## Cel projektu

Celem projektu jest praktyczne poznanie sposobu pracy z plikami w repozytorium oraz przygotowanie czytelnej dokumentacji projektu.

## Wykorzystane elementy Markdown

W tym pliku zastosowano podstawowe elementy składni Markdown:

1. Nagłówki pierwszego i drugiego poziomu.
2. Listę punktowaną.
3. Listę numerowaną.
4. **Pogrubienie tekstu**.
5. *Kursywę tekstu*.
